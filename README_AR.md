# CampusVoice — University Complaint Management System

مشروع PHP وMariaDB لإدارة شكاوى الجامعة. يستطيع الطالب إنشاء حساب وتقديم شكوى ومتابعة حالتها والردود عليها. يستطيع المسؤول البحث في الشكاوى وعرضها وتعديلها وتحديث حالتها والرد عليها وحذفها بأمان، إضافة إلى البحث في المستخدمين وتحديث بياناتهم. تعتمد لوحة الإدارة على REST API و`fetch()`، وتحمي الصفحات والواجهات بالجلسات والصلاحيات وCSRF.

## التشغيل المحلي باستخدام XAMPP

1. شغّل Apache وMySQL من XAMPP، وضع ملفات المشروع مباشرة داخل `htdocs/university_complaints`.
2. إذا لم تكن قاعدة البيانات موجودة، استورد `database/schema.sql` من phpMyAdmin. إذا كانت قاعدة `university_complaints_db` وجداول `users` و`complaints` و`responses` موجودة مسبقًا، احتفظ بها. الملف يستخدم `CREATE ... IF NOT EXISTS` ولا يحذف البيانات.
3. ملف `db.php` موجود الآن في المشروع. إعداداته الافتراضية مناسبة لـXAMPP المحلي: `127.0.0.1:3306`، قاعدة `university_complaints_db`، والمستخدم `root` بلا كلمة مرور. لتغييرها استخدم متغيرات البيئة `DB_HOST` و`DB_PORT` و`DB_NAME` و`DB_USER` و`DB_PASSWORD` بدل تعديل الشيفرة.
4. شغّل فحص البيئة من سطر الأوامر:

   ```bash
   /d/php/php/php.exe scripts/check_environment.php
   ```

   يجب أن تظهر رسالة نجاح تفيد بوجود امتداد `pdo_mysql` والجداول الثلاثة وعلاقات المفاتيح الأجنبية. إذا ظهرت أسماء أعمدة ناقصة، طابق قاعدة بياناتك الحالية مع `database/schema.sql` دون حذف بياناتك.
5. لإنشاء حساب طالب ومسؤول تجريبيين محليًا:

   ```bash
   /d/php/php/php.exe scripts/seed_demo.php
   ```

   احتفظ بكلمتي المرور اللتين يعرضهما الأمر. إعادة تشغيله تغيّر كلمات مرور حسابي التجربة فقط.
6. لإنشاء حساب مسؤول حقيقي محليًا، شغّل الأمر التالي وأدخل الاسم والبريد. سيولّد البرنامج كلمة مرور قوية مرة واحدة:

   ```powershell
   & "D:\php\php\php.exe" "scripts\create_admin.php"
   ```

7. افتح `http://localhost/university_complaints/`.

## مسار تجربة النظام

1. ادخل بحساب الطالب `student.demo@example.test`، وقدّم شكوى ثم افتح تفاصيلها.
2. سجّل الخروج وادخل بحساب المسؤول `admin.demo@example.test`، ثم غيّر الحالة وأرسل ردًا.
3. ارجع إلى حساب الطالب وتأكد من ظهور الحالة والرد، ثم جرّب تسجيل طالب جديد؛ الحساب الجديد يملك دور الطالب فقط.
4. اعرض `diagram.php` لمقارنة العلاقات والوظائف بالمخطط. ملف `database/verify_relations.sql` يحتوي استعلامات الفحص الإضافية.

## بنية المشروع

- `db.php`: اتصال PDO بقاعدة MariaDB مع قيم XAMPP المحلية ومتغيرات البيئة.
- `helpers.php`: الجلسة، فحص الأدوار، حماية CSRF، وتنسيق الصفحات.
- `register.php` و`login.php` و`logout.php`: إدارة الحساب والدخول.
- `student.php` و`new_complaint.php`: لوحة الطالب وتقديم الشكوى.
- `admin.php` و`complaint.php`: عرض الشكاوى وتحديث الحالة والرد.
- `users.php`: البحث في حسابات الطلاب والمسؤولين وتحديث الاسم والبريد، مع منع تعديل الأدوار.
- `api/complaints.php`: عرض الشكاوى وتعديل تفاصيلها وحذفها بعد حذف الردود التابعة داخل معاملة.
- `api/update_complaint.php`: تحديث الحالة وإضافة رد إداري داخل معاملة واحدة.
- `api/users.php`: عرض المستخدمين وتحديث بياناتهم للمسؤولين فقط.
- `assets/admin.js` و`assets/users.js` و`assets/complaint.js`: ربط لوحة الإدارة بالواجهات باستخدام `fetch()`.
- `scripts/check_environment.php`: فحص امتدادات PHP والبنية والعلاقات، من سطر الأوامر فقط.
- `scripts/seed_demo.php`: إنشاء حسابات اصطناعية للعرض المحلي فقط.
- `scripts/create_admin.php`: إنشاء مسؤول محلي بكلمة مرور مولّدة عشوائيًا.

## واجهات REST API

| الطريقة | المسار | الوظيفة |
|---|---|---|
| `GET` | `api/complaints.php` | عرض الشكاوى؛ يرى الطالب شكاواه فقط ويرى المسؤول جميع الشكاوى |
| `GET` | `api/complaints.php?id=1` | عرض شكوى واحدة مع التحقق من الملكية |
| `PATCH` | `api/complaints.php?id=1` | تعديل عنوان الشكوى وتصنيفها ووصفها للمسؤول |
| `PATCH` | `api/update_complaint.php` | تحديث الحالة وإضافة رد للمسؤول |
| `DELETE` | `api/complaints.php?id=1` | حذف الشكوى وردودها للمسؤول بعد تأكيد الواجهة |
| `GET` | `api/users.php` | عرض المستخدمين والبحث فيهم للمسؤول |
| `PATCH` | `api/users.php` | تحديث الاسم والبريد فقط؛ لا تقبل الواجهة تعديل الدور |

طلبات التعديل والحذف تتطلب جلسة مسؤول صالحة ورمز CSRF في ترويسة `X-CSRF-Token`. جميع الاستعلامات تستخدم PDO Prepared Statements، وتستخدم العمليات المرتبطة معاملات قاعدة بيانات.

## تحديث نسخة Windows الحالية بأمان

لا تحذف قاعدة البيانات؛ فهي محفوظة في MariaDB وليست داخل مجلد المشروع. قبل استبدال الملفات، أوقف Apache مؤقتًا حتى لا يبقى المجلد مقفولًا، ثم احتفظ بنسخة من مجلد المشروع. بعد نسخ النسخة الجديدة، شغّل:

```powershell
Set-Location "D:\php\htdocs\university_complaints"
& "D:\php\php\php.exe" "scripts\check_environment.php"
Get-ChildItem -Recurse -Filter "*.php" | ForEach-Object { & "D:\php\php\php.exe" -l $_.FullName }
```

أعد تشغيل Apache وMySQL بعد نجاح الفحص، ثم افتح الموقع وجرّب مسار الطالب ومسار المسؤول قبل حذف النسخة الاحتياطية.

هذا مشروع جامعي للتشغيل المحلي. النشر العام يحتاج إعداد خادم وقاعدة بيانات آمنين، مستخدم قاعدة بيانات محدود الصلاحيات، وإزالة حسابات العرض التجريبي. لا تضع بيانات أشخاص حقيقيين في نسخة العرض.
